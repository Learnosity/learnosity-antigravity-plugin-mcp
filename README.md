# Learnosity Build Aide

**Build Learnosity integrations directly from Antigravity.**

![MCP: Streamable HTTP](https://img.shields.io/badge/MCP-Streamable_HTTP-01313E)
![Auth: none](https://img.shields.io/badge/auth-none-01313E)
![Tools: read-only](https://img.shields.io/badge/tools-read--only-01313E)
![License: GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-EB3C3F)

Install the plugin and your agent can answer from Learnosity's own documentation, API references
and guided integration Skills. There is no account to create, no API key to paste and no
configuration file to edit.

## Features

- 📚 **Source-backed answers** from the Learnosity Help Site, Author Guide, Feedback Aide docs,
  Demos and public GitHub repositories, with citations.
- 🧭 **Integration Skills** for the golden path (Author, Items, Reports), request signing, LTS
  upgrades, content migration and more, bundled with the plugin and available as `/<skill-name>`.
- 🔒 **Read-only and authless.** The server never asks for, receives or stores your consumer key or
  secret.

## Get started

1. Install the plugin from the Antigravity Marketplace, or from this repository:

   ```bash
   agy plugin install https://github.com/Learnosity/learnosity-antigravity-plugin-mcp
   ```

2. Ask your agent, for example:
   *"How do I sign an Items API request in Node.js?"*

The plugin connects to the remote server at `https://mcp.learnosity.com/build/build-aide`. It bundles
no server code.

## Tools

| Tool | Purpose |
| --- | --- |
| `search_docs_sources` | Search the indexed Learnosity documentation |
| `read_document` | Read a document in full |
| `list_docs_sources` / `list_docs_categories` | Discover sources and categories |
| `skills_list` / `skills_search` / `skills_read` | Find and read integration Skills |
| `get_feedback_link` | Get the link to share feedback |
